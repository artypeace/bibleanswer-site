# Verse of the Day

Actual native Verse of the Day sheets, captured and visually reviewed in all six
languages on 2026-10-02. Full captures are proportionally downscaled to WebP.
See `assets/inside/README.md` and `assets/inside/sources.json` for capture provenance.

The daily section shows the verse sheet, the actual Morning prayer screen from
`assets/story/hours/`, and the real Apple Watch app screen in an original housing.
These are labelled as app screens, not Home Screen or Lock Screen widget captures.
