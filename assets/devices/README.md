# Device previews

These housings are original vector illustrations, authored for Bible Answer.
They are not official Apple product renders or Apple Design Resources.
Each contains a real native screenshot, proportionally downscaled and encoded
as WebP. The source screen is not retouched or redrawn.

The iPhone, iPad and Mac images show the native home screen in each language.
Apple Watch uses the app’s existing native `01-word.png` capture in each language.
The phone cutout, watch band and laptop base are physical housing artwork.

Regenerate with `tools/make_device_previews.py` (Pillow required). Source hashes
and dimensions are recorded in `sources.json`; raw PNGs stay outside this repo.
