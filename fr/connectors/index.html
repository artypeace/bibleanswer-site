Claude

Ouvrez Customize → Connectors → Add custom connector. Saisissez Bible Answer comme nom et collez l’adresse. Si Claude demande un mode de connexion, choisissez No sign in. Activez Bible Answer dans le menu Connectors de la conversation.

Ouvrir Claude

Grok

Ouvrez Connectors → New Connector → Custom. Saisissez Bible Answer comme nom, collez l’adresse, puis sélectionnez Add Connector.

Ouvrir les connecteurs de Grok

Codex

Exécutez cette commande dans le terminal, puis ouvrez une nouvelle session Codex.

codex mcp add bible-answer --url https://mcp.bibleanswer.app/mcp
