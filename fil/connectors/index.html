Bible Answer sa Claude, Grok at Codex

Maghanap ng mga gabay sa pagbasa ng Bibliya, eksaktong sipi, at link sa pinagmulan sa Claude, Grok, o Codex.

Address ng connector

https://mcp.bibleanswer.app/mcp

Kopyahin ang address na ito para ikonekta ang Bible Answer. Nagbabasa ito ng mga nailathalang gabay sa anim na wika. Hindi kailangan ng Bible Answer account.

Claude

Buksan ang Customize → Connectors → Add custom connector. Ilagay ang Bible Answer bilang pangalan at i-paste ang address. Kung hihingi ng paraan ng pag-sign in, piliin ang No sign in. I-on ang Bible Answer sa menu ng Connectors sa chat.

Buksan ang Claude

Grok

Buksan ang Connectors → New Connector → Custom. Ilagay ang Bible Answer bilang pangalan, i-paste ang address, at piliin ang Add Connector.

Buksan ang Grok Connectors

Codex

Patakbuhin ang command na ito sa terminal, at pagkatapos ay magsimula ng bagong session sa Codex.

codex mcp add bible-answer --url https://mcp.bibleanswer.app/mcp

Subukang magtanong

Gamitin ang Bible Answer para maghanap ng gabay sa Awit 23 sa Filipino. Sabihin kung anong salin ng Bibliya ang sinipi at ibigay ang link sa orihinal na gabay.
