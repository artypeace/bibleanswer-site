Connector address

https://mcp.bibleanswer.app/mcp

Copy this address to connect Bible Answer. It reads published guides in six languages and does not require a Bible Answer account.

Claude

Open Customize → Connectors → Add custom connector. Enter Bible Answer as the name and paste the address above. Choose No sign in if prompted. Enable Bible Answer in the chat’s Connectors menu.

Open Claude

Grok

Open Connectors → New Connector → Custom. Enter Bible Answer as the name, paste the address above, then select Add Connector.

Open Grok Connectors

Codex

Run this command in your terminal. Start a new Codex session after adding the connector.

codex mcp add bible-answer --url https://mcp.bibleanswer.app/mcp
